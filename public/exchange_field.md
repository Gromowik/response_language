# Поле обмена (Exchange Field) — TODO и разговор

Живой документ: план реализации отдельного «поля игры», где люди соединяются для обмена, и конспект разговора о смысле.  
Сюда же можно дописывать новые мысли по ходу — потом пригодится для объяснения работы.

Связанные проекты:
- Object Tape / response language (этот репозиторий) — язык внимания и обмена
- [unfolding-programs](https://unfolding-programs.vercel.app/) — проекции понимания

---

## 1. Зачем это поле

Object Tape хорошо показывает **как устроен обмен объектами внимания**.  
Недостающий слой: **кто** входит в обмен и **как найти** человека для резонанса.

Тема сама по себе — инструмент стыковки.  
Резонанс **U** часто рождается от персонального: голос, манера, ценности, способ смотреть, сегодняшнее состояние.

Поле обмена = площадка встречи.  
Object Tape = язык самого обмена после встречи.

## 2. Суть модели (конспект разговора)

### Связка «тема ↔ Я»

- **Тема** — вход, общий предмет, поиск «по делу».
- **Я** — презентация человека в этой теме (и шире — выражение себя).
- Важно передать не только общую тему, а **себя в ней**, и более того — **самого себя как главное**.

### Презентация не единая

«Я» не обязано быть одним навсегда для всех.

Можно (по желанию) подобрать презентацию ближе к теме:
- элемент тебя;
- твоего восприятия темы;
- сегодняшнего настроения, состояния, выражения.

То есть **Я-в-теме-сейчас**, которое можно уточнять всё лучше — не одна анкета для всех миров.

### Много карточек / проекций

Игрок может иметь много карточек по теме — проекций.  
От темы к персональному — без жёсткого потолка: так богаче выбор и точнее сцепление.

Как в unfolding: объект (здесь — встреча людей) «расщепляется» на проекции, с которых его лучше видно.  
Выбор общих ценных проекций усиливает сцепление и делает градиент общения точнее.

### Поиск

Искать можно:
- по **теме**;
- по **персональному** совпадению в описании «Я»;
- **оба поля вместе** или по отдельности — для более точного нахождения игроков, с которыми хочется обмениваться.

### Ритм обмена (из общей философии лент)

После нахождения возможен обмен:
- **с задержкой** — анализ, раздумье, уточнение (это нормально);
- **мгновенный** — яркий живой интерес, новые темы и отражения.

Обучение / общение в таком режиме — не долг «выучить», а вместе почувствовать, понять красоту, порадоваться и «переварить».

### Цепочка встречи (черновик)

1. Человек живёт с лентой / карточками вокруг темы.  
2. Другой находит его по теме и/или по «Я».  
3. Видит презентацию (текст, по возможности видео ~10 мин).  
4. Создаёт отражения / отклик.  
5. Если интересно — вступают в обмен (сразу или позже).

## 3. Принципы дизайна (чтобы не размыть смысл)

1. **«Я» — отдельный акцент карточки**, не смешивать с обычным Generated по теме без различия.  
2. **Видео опционально**, текст «Я» желателен для поиска и доверия.  
3. **Поле игры отдельно** от калькулятора лент; связь — через тему, карточку, позже через переход к лентам.  
4. **Приватность**: что видно в поиске сразу, что открывается после взаимного интереса — решить до большой аудитории.  
5. Улучшать **потихоньку**, обсуждая здесь и дописывая этот файл.

## 5. Открытые вопросы для следующих разговоров

1. Название в UI: Exchange Field / Поле обмена / Поле игры / Встреча?  
2. «Я» обязательно для публикации в поиске или можно сначала только тему?  
3. Видео: только ссылка (YouTube и т.п.) или позже загрузка?  
4. После взаимного интереса — что является «началом обмена» в продукте?  
5. Карточки чужих игроков в первой версии: только демо-набор или импорт JSON «витрины»?  
6. Нужна ли сразу модерация / возрастные границы для публичных «Я»?
7. Как в данных отличить «трансляцию объектов темы» от «пары отражений двух персон»?
8. Кто может ставить вес трансляции / уточнять In: только автор, наблюдатель, ИИ-помощник?
9. U-фильтр: порог абсолютный, или «U / мощность узла», или топ-N пиков?
10. Формат стыковки с движком тем: общий JSON связей, API, или пока только концептуальная совместимость языка?
11. В игре программ: U = соответствие ожиданию или ещё и «смещение/новизна» как отдельная метрика?
