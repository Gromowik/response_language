# Сборник сидов (почва для упражнений)

Важный формат: учиться думать на языке трансляций, обмениваться с ИИ и готовить почву, которой можно воспользоваться всегда. При желании или необходимости из сида собирается своё, более детальное поле карточек на странице **Reflection** — на свой вкус.

Короткие и длинные размышления удобно хранить здесь как материал для упражнений.

| id | файл | тема |
|----|------|------|
| lever-basics | `/example.md` | Рычаг / работа / мощность — первый сид |
| gears-engagement | `/work/dialog_2.md` | Два колеса в зацеплении — инварианты и «обманка» радиуса |

Дальше новые сиды можно класть в `public/work/` и добавлять в `catalog.json`.
