# Сборник сидов (почва для упражнений)

Важный формат: учиться думать на языке трансляций, обмениваться с ИИ и готовить почву. При желании из сида или **истории** собирается своё поле карточек на **Reflection**.

Классы в каталоге (`catalog.json`):

- `seed` — разборы и заметки  
- `history` — трек трансляций от своего лица (опора на модели облака)

Пример истории: `history_cycling.md` (катание).


| id | файл | тема |
|----|------|------|
| lever-basics | `/example.md` | Рычаг / работа / мощность — первый сид |
| gears-engagement | `/work/dialog_2.md` | Два колеса в зацеплении — инварианты и «обманка» радиуса |

Дальше новые сиды можно класть в `public/work/` и добавлять в `catalog.json`.
