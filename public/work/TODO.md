Поток: **прошёл по объекту → кликнул → добавил на ленту**. Карточка с тем, что видите (пример с Работой A + формула + подсветка me/load) — точка интереса; потом отдельное окно: комментарий, порядок, удаление.

| Действие | Смысл |
|----------|--------|
| Клик по узлу/центру → «на ленту» | точечный набор внимания |
| **Перенять всё из объекта** | автозаполнение по канону порядка → правите |
| Порядок авто-перенятия | **O → ВО** (как на кольце) → **центры** от O наружу (важность/мощность) |
| После обработки | запуск в общение → **Person 1 Tape** (пока целое; позже объект раскрывается во времени) |

Это мост **рабочий отпечаток → витринный Person Tape**, не ломая Сид: лента внимания живёт в рабочей среде, «запустить в общение» копирует/открывает снимок как Person 1.

### Порядок относительно моделей

- На **входе** лента внимания кормится кликами по ВО и вычислительным центрам (уже с подсветкой).  
- На **выходе** — кликами по трансляциям и узлам ВО (работа, мощность…).  
- Телескоп всегда рядом: «что именно ушло в карточку ленты» = тот же id, что в JSON.

### Осторожный следующий шаг в коде (когда скажете)

1. Телескоп-панель (read-only JSON объекта / selection).  
2. `attentionTape` в localStorage рабочей среды: add from selection, reorder, edit note, «перенять всё».  
3. Кнопка «→ в общение / Person 1» — экспорт ленты в формат карточек (или RL Trial tape), без переписывания витрины.

**Итог:** телескоп = контроль нижнего слоя данных; ленты внимания = ваш проход, собранный в поток к Person 1. Логичное продолжение после Ring Demo вход/выход. Готов собрать каркас по вашей отмашке.
