# Object Tape Calculator

React + Vite приложение для визуализации и управления объектами внимания с поддержкой симуляции обмена между двумя персонами.

## Основная функциональность

### Ленты объектов

1. **Horizontal Tape (Person 1 Tape)** - горизонтальная лента для первого человека
2. **Person 2 Tape** - горизонтальная лента для второго человека (для симуляции обмена)
3. **Vertical Person 1** - вертикальная лента для Person 1 (по центру экрана)
4. **Vertical Person 2** - вертикальная лента для Person 2 (по центру экрана)
5. **Both Vertical** - обе вертикальные ленты одновременно
6. **Circular Tape** - круговая лента
7. **Both Circular** - две независимые круговые ленты (по одной для каждой персоны)
8. **Paired Circular** - две круговые ленты с соединенными парами объектов (шестеренки)
9. **Philosophie** - страница с философией проекта
10. **README** - чтение файла `README.md` прямо в приложении

### Типы объектов

Каждый объект имеет один из трех типов:

- **Generated (Сгенерированный)** - оттенки синего/голубого (#3498DB, #5DADE2, #85C1E2, #2980B9, #1E90FF)
- **External Reflection (Отраженный внешний)** - оттенки зеленого (#2ECC71, #52BE80, #27AE60, #1ABC9C, #16A085)
- **Internal Reflection (Отраженный внутренний)** - оттенки коричневого (#8B4513, #A0522D, #CD853F, #D2691E, #DEB887)

При выборе типа цвет автоматически устанавливается в соответствии с типом.

### Метрики объектов

- **IN** - метрика удовлетворенности владельца объектом (диапазон 0-10)
  - Показывает, насколько сам владелец объекта (участник, для которого создан объект) удовлетворен/воспринимает этот объект
  - Для объекта на левой стороне: IN = удовлетворенность левого участника
  - Для объекта на правой стороне: IN = удовлетворенность правого участника

- **OUT** - метрика удовлетворенности партнера этим объектом (диапазон 0-10)
  - Показывает, насколько партнер (участник с другой стороны) удовлетворен/воспринимает это же явление через свое отражение
  - Для объекта на левой стороне: OUT = удовлетворенность правого участника этим объектом
  - Для объекта на правой стороне: OUT = удовлетворенность левого участника этим объектом
  - В системе пар: OUT одного объекта = IN его парного отражения (и наоборот)

- **U** - резонанс/радость (любое положительное число, без ограничений)
  - Индивидуальная метрика радости/резонанса от объекта, не синхронизируется между парами

### Фокусы внимания

1. **Общий фокус** (золотая рамка справа) - текущий фокус внимания при движении по ленте
2. **Особый фокус** (фиолетовая рамка, круг над лентой) - объект отдельного рассмотрения
   - Объект остается на своем месте в ленте
   - Дублируется над лентой в центре как круг
   - При попадании в особый фокус записывается временная метка `focusedAt`
   - При загрузке все объекты получают одинаковую стартовую временную метку

### Управление лентой

- **Кнопки навигации**: ← Previous / Next →
- **Служебный квадратик с прокруткой**: колесико мыши для прокрутки ленты
- **Перемещение объектов**: drag & drop на ленте
- **Кнопка "→ To Focus"**: перемещает выделенный объект в общий фокус (справа)
- **Кнопка "⬆ Special Focus"**: перемещает выделенный объект в особый фокус (над лентой)
- **Кнопка "✕ Clear Special"**: очищает особый фокус

### Работа с карточками

- **Создание**: кнопка "+ New Card"
- **Редактирование**: двойной клик на объекте или клик на выделенном объекте
- **Экспорт/Импорт**: кнопки Export JSON / Import JSON
- **Хранение**: автоматическое сохранение в localStorage

### Временные метки

- **focusedAt** - время попадания объекта в особый фокус рассмотрения
- При первой загрузке все объекты получают одинаковую временную метку (время загрузки)
- При попадании объекта в особый фокус метка обновляется текущим временем
- Используется для определения актуальных интересов персон
- Время последнего попадания в фокус отображается в редакторе карточек

### Система пар объектов (Симметрия между персонами)

Каждый объект типа **Generated** или **Internal Reflection** автоматически создает свое **External Reflection** на ленте другой персоны. Это создает систему парных объектов:

1. **Автоматическое создание пар**:
   - При создании объекта типа Generated или Internal Reflection на ленте одной персоны автоматически создается его External Reflection на ленте другой персоны
   - Внешние отражения нельзя создавать вручную - они создаются только автоматически

2. **Синхронизация метрик между парами**:
   - **IN ↔ OUT**: метрики синхронизируются динамически между парными объектами, отражая симметрию удовлетворенности
     - IN исходного объекта = OUT его отражения (удовлетворенность владельца исходного объекта = удовлетворенность партнера через его отражение)
     - OUT исходного объекта = IN его отражения (удовлетворенность партнера исходным объектом = удовлетворенность владельца отражения)
     - Это обеспечивает симметрию: как один участник воспринимает объект, так партнер воспринимает его отражение
   - **U (резонанс)**: остается индивидуальным для каждого объекта (не синхронизируется между парами)
   - При изменении метрик одного объекта автоматически обновляются метрики его пары

3. **Синхронизация описания и имени**:
   - Описание (description) синхронизируется между парными объектами
   - При изменении имени исходного объекта имя отражения обновляется автоматически
   - В карточке отражения сохраняется имя исходного объекта (`pairName`)

4. **Ограничения на редактирование**:
   - Тип объекта нельзя изменить после создания (отображается как неизменяемое поле)
   - Внешние отражения создаются только автоматически (недоступны при создании новой карточки)

5. **Отображение информации о паре**:
   - В редакторе карточек отображается информация о парном объекте:
     - Для External Reflection показывается имя исходного объекта
     - Для Generated/Internal Reflection показывается имя его внешнего отражения
   - На странице Both Vertical Tapes парные объекты соединяются пунктирными линиями

6. **Удаление пар**:
   - При удалении объекта автоматически удаляется его внешнее отражение (и наоборот)
   - Это обеспечивает целостность системы пар

### Технические детали

- localStorage для хранения данных
- Модульные CSS стили
- Поддержка двух персон с отдельными наборами объектов

## Последние изменения

### Circular Tape (Круговая лента)

**Важная диаграмма** для визуализации объектов в круговом формате:

1. **Визуализация объектов**:
   - Объекты отображаются **полными кругами** (не полукругами) для лучшей видимости
   - Объекты **приподняты основанием вверх** от оболочки круга (центр круга находится на окружности)
   - Это создает более наглядное и эстетичное представление объектов

2. **Функциональность**:
   - **Кнопка "Send to Circular"** на каждой горизонтальной ленте (Person 1 и Person 2):
     - Отправляет видимые объекты (до 10) с горизонтальной ленты на Circular Tape
     - Объект в фокусе (самый правый на горизонтальной ленте) размещается сверху на окружности (позиция 0)
     - Объекты слева от фокуса идут по часовой стрелке вокруг окружности (в обратном порядке для визуального соответствия)
     - Автоматически переключает на страницу Circular Tape
   - Drag & Drop для переупорядочивания объектов по кругу
   - Прокрутка круга колесиком мыши или кнопками для просмотра всех объектов
   - Выделение объектов для редактирования
   - Фокус всегда на верхнем объекте (индекс 0)
   - Изменения, внесенные на Circular Tape, сохраняются в исходных объектах Person 1 или Person 2

### Улучшения Circular Tape (Круговая лента)

1. **Полные круги вместо полукругов**: объекты теперь отображаются полными кругами для лучшей видимости и эстетики
2. **Приподнятое основание**: объекты приподняты основанием вверх от оболочки круга (центр круга находится на окружности), что создает более наглядное представление
3. **Увеличен размер объектов**: размер объектов на круговой ленте увеличен с 40 до 70 пикселей
4. **Горизонтальные названия**: названия объектов всегда отображаются горизонтально для удобства чтения
5. **Кнопка "Send to Circular"** на горизонтальных лентах:
   - Доступна на лентах Person 1 и Person 2
   - Отправляет видимые объекты (до 10) на Circular Tape
   - Объект в фокусе (самый правый на горизонтальной ленте) размещается сверху на окружности
   - Объекты слева от фокуса идут по часовой стрелке (в обратном порядке для визуального соответствия)
   - Автоматически переключает на страницу Circular Tape
   - Изменения, внесенные на Circular Tape, сохраняются в исходных объектах соответствующей персоны
6. **Прокрутка колесиком мыши**: добавлен служебный квадратик для прокрутки круга колесиком мыши (аналогично Horizontal Tape)
7. **Drag & Drop**: возможность переупорядочивания объектов по кругу путем перетаскивания

### Both Circular Tapes (Обе круговые ленты)

1. **Две независимые круговые ленты**:
   - Левая окружность отображает объекты первой персоны (Person 1)
   - Правая окружность отображает объекты второй персоны (Person 2)
   - Каждая окружность работает независимо от другой

2. **Визуализация объектов**:
   - Объекты отображаются **полными кругами** (шестеренки)
   - Объекты **приподняты на 3/4 своего радиуса** от окружности (эффект шестеренки)
   - Это создает визуальный эффект "шестеренок", которые взаимодействуют с окружающими объектами

3. **Фокус и порядок объектов**:
   - Показываются **10 видимых объектов** с каждой горизонтальной ленты
   - **Верхний объект** (позиция 0) = объект в общем фокусе (самый правый на горизонтальной ленте)
   - Объекты слева от фокуса на горизонтальной ленте идут **по часовой стрелке** вокруг окружности
   - Каждая окружность отражает текущее состояние своей горизонтальной ленты

4. **Функциональность**:
   - Двойной клик на объекте для редактирования
   - Изменения сохраняются в соответствующих объектах Person 1 или Person 2
   - Визуальное представление актуального фокуса и видимых объектов каждой персоны

5. **Философия**:
   - Две независимые "шестеренки", каждая отражает свою персону
   - Позволяет видеть, как каждая персона видит свои объекты в круговом представлении
   - Каждая окружность показывает свой собственный фокус и порядок объектов

### Paired Circular Tapes (Парные круговые ленты)

1. **Две синхронизированные круговые ленты (шестеренки)**:
   - Левая окружность отображает объекты первой персоны (Person 1)
   - Правая окружность отображает объекты второй персоны (Person 2)
   - Окружности **жестко связаны парами объектов**, создавая эффект "шестеренок"

2. **Визуализация объектов**:
   - Объекты отображаются **полными кругами** (шестеренки)
   - Объекты **приподняты на 3/4 своего радиуса** от окружности (эффект шестеренки)
   - Парные объекты визуально "сцепляются" друг с другом, имитируя механизм шестеренок

3. **Точка зацепления (engagement point)**:
   - **Точка зацепления** - место, где окружности наиболее близки друг к другу
   - **Левая окружность**: точка зацепления находится **справа** (угол 0, правый край)
   - **Правая окружность**: точка зацепления находится **слева** (угол π, левый край)
   - Первая пара (idx=0) находится в точке зацепления и визуально "сцепляется"
   - Индикаторы (желтые стрелки) показывают точку зацепления на каждой окружности

4. **Направление вращения**:
   - **Левая окружность**: объекты идут **против часовой стрелки** от точки зацепления (наверх)
   - **Правая окружность**: объекты идут **по часовой стрелке** от точки зацепления (наверх)
   - Это создает эффект синхронизированного вращения "шестеренок" - когда одна вращается, другая вращается в противоположном направлении

5. **Сортировка пар**:
   - Используется та же логика сортировки, что и в **Both Vertical Tapes**:
     - **Сортировка по метрикам (IN+OUT)**: Сортировка по сумме метрик IN + OUT (по убыванию)
       - Пары с наибольшей общей удовлетворенностью (IN + OUT) отображаются в точке зацепления (первыми)
     - **Сортировка по времени фокуса (Focus Time)**: Сортировка по сумме "возрастов" фокуса пары (по возрастанию)
       - Пары, которые недавно рассматривались обоими участниками, отображаются в точке зацепления (первыми)
   - Порядок пар согласован с Both Vertical Tapes (та же логика сортировки)

6. **Визуальные связи**:
   - Парные объекты соединяются линиями для визуального представления связей
   - Пара в точке зацепления (idx=0) может иметь особое выделение (тонкая сплошная линия)
   - Остальные пары соединяются пунктирными линиями

7. **Навигация**:
   - Кнопки **← Previous** и **Next →** для вращения "шестеренок"
   - Вращение синхронизировано - обе окружности вращаются вместе
   - Можно просматривать все пары объектов, вращая окружности

8. **Функциональность**:
   - Двойной клик на объекте для редактирования
   - Изменения сохраняются в соответствующих объектах Person 1 или Person 2
   - Переключатель режимов сортировки (IN+OUT / Focus Time)

9. **Философия**:
   - Две "шестеренки", соединенные парами объектов, имитируют синхронизированный механизм взаимодействия
   - Точка зацепления показывает текущий фокус взаимодействия - пару объектов, которые "сцепляются" в данный момент
   - Синхронизированное вращение отражает согласованное движение объектов в процессе обмена между персонами
   - Это визуальное представление того, как пары объектов взаимодействуют друг с другом, создавая эффект "шестеренок", которые работают вместе

### Изменения Both Vertical Tapes

1. **Интеграция с персонами**: 
   - Левая вертикальная лента теперь отображает объекты первой персоны (`cards`)
   - Правая вертикальная лента отображает объекты второй персоны (`cardsPerson2`)
   - Это позволяет видеть объекты обеих персон друг против друга для сравнения и симуляции обмена

2. **Увеличение расстояния между плоскостями**:
   - Расстояние между левой и правой плоскостями увеличено в 1.5 раза
   - Левая плоскость сдвинута влево (x = width - 300, было width - 200)
   - Правая плоскость сдвинута вправо (x = 300, было 200)
   - Это улучшает визуальное восприятие пар объектов и линий связи между ними

3. **Сортировка пар объектов и горизонтальное выравнивание**:
   - Реализованы два режима сортировки пар объектов, доступные через переключатель в панели управления:
     - **Сортировка по метрикам (IN+OUT)**: Сортировка по сумме метрик IN + OUT (по убыванию)
       - Сумма IN + OUT показывает общую удовлетворенность парой: удовлетворенность владельца (IN) + удовлетворенность партнера (OUT)
       - Пары с наибольшей общей удовлетворенностью (IN + OUT) отображаются выше
     - **Сортировка по времени фокуса (Focus Time)**: Сортировка по сумме "возрастов" фокуса пары (по возрастанию)
       - Для каждой пары вычисляется сумма "возрастов" фокуса: (текущее время - focusedAt левого объекта) + (текущее время - focusedAt правого объекта)
       - Чем меньше сумма, тем недавнее оба объекта были в фокусе особого внимания у своих владельцев
       - Пары, которые недавно рассматривались обоими участниками, отображаются выше
       - Эта опция позволяет наблюдать не только самые важные пары (по метрикам удовлетворенности), но и то, что было в фокусе внимания у обоих участников недавно
       - Полезно для выявления актуальных тем, которые оба участника рассматривали синхронно
   - Левая лента служит основой для упорядочивания (пары формируются по левой стороне)
   - Правая лента формируется по парам относительно левой, обеспечивая горизонтальное выравнивание парных объектов
   - Все пары объектов отображаются на одной горизонтальной линии (одинаковая Y-координата)
   - При смене режима сортировки прокрутка автоматически возвращается к началу списка

4. **Общие элементы управления**:
   - Удалено перетаскивание объектов мышкой (drag & drop)
   - Реализована общая прокрутка для обеих лент (вместо отдельных кнопок для каждой стороны)
   - Добавлен переключатель режимов сортировки:
     - Кнопка "IN+OUT" - сортировка по сумме метрик IN + OUT (удовлетворенность парой)
     - Кнопка "Focus Time" - сортировка по сумме возрастов фокуса (недавность рассмотрения обоими участниками)
     - Активный режим подсвечивается цветом
   - Остается возможность редактирования объектов двойным кликом

5. **Визуализация векторов IN (удовлетворенность владельца объектом)**:
   - Для каждого объекта добавлен вектор, показывающий метрику IN - удовлетворенность владельца этим объектом
   - Левая плоскость: векторы направлены влево (наружу от плоскости), показывают удовлетворенность левого участника своими объектами
   - Правая плоскость: векторы направлены вправо (наружу от плоскости), показывают удовлетворенность правого участника своими объектами
   - Длина вектора пропорциональна значению IN (0-10) - чем выше удовлетворенность владельца, тем длиннее вектор
   - Максимальная длина вектора (при IN = 10) равна половине расстояния между плоскостями (300 пикселей)
   - Формула длины: `(IN / 10) * 300`
   - Векторы визуально показывают силу удовлетворенности каждого участника своими объектами и их восприятие парных объектов на противоположной стороне

### Система синхронизации пар объектов

1. **Автоматическое создание внешних отражений**:
   - При создании Generated или Internal Reflection автоматически создается External Reflection на другой ленте
   - Внешние отражения нельзя создавать вручную

2. **Синхронизация метрик IN ↔ OUT**:
   - Метрики динамически синхронизируются между парными объектами, отражая симметрию удовлетворенности
   - IN одного объекта = OUT его пары: удовлетворенность владельца исходного объекта = удовлетворенность партнера через его отражение
   - OUT одного объекта = IN его пары: удовлетворенность партнера исходным объектом = удовлетворенность владельца отражения
   - U (резонанс) остается индивидуальным для каждого объекта (не синхронизируется)

3. **Синхронизация описания и имени**:
   - Описание синхронизируется между парными объектами
   - Имя отражения обновляется при изменении имени исходного объекта

4. **Визуализация связей**:
   - На странице Both Vertical Tapes парные объекты соединяются пунктирными линиями
   - Парные объекты располагаются друг напротив друга

5. **Информация о парах в редакторе**:
   - Отображается имя парного объекта (исходного или отражения)
   - Показывается время последнего попадания в особый фокус (`focusedAt`)

### Изменения Vertical Person 1 и Vertical Person 2

1. **Две вертикальные ленты рядом (как Both Vertical)**:
   - Vertical Person 1 и Vertical Person 2 теперь показывают две вертикальные ленты рядом
   - **Левая лента**: Порядок из горизонтальной Person Tape (собственный порядок пользователя)
   - **Правая лента**: Порядок из Both Vertical для этой персоны (с учетом взаимодействия, с сортировкой)
   - Vertical Person 2 показывает ленты Person 2, Vertical Person 1 показывает ленты Person 1
   - **Удобство визуализации**: 
     - В **Vertical Person 1** и **Vertical Person 2** на обеих лентах объекты расположены слева от вертикальных линий
     - **Левая лента**: Векторы IN направлены влево (наружу от плоскости)
     - **Правая лента**: Векторы IN направлены вправо (наружу от плоскости) для лучшей видимости и удобства восприятия
     - Это обеспечивает единообразное визуальное представление и хорошо видимые векторы на обеих страницах

2. **Интеграция с горизонтальными лентами и Both Vertical**:
   - Левая вертикальная лента = порядок из горизонтальной Person Tape (как есть, без изменений)
   - Правая вертикальная лента = порядок из Both Vertical для этой персоны (с сортировкой как в Both Vertical)
   - Используются те же карточки, что и в соответствующих горизонтальных лентах
   - Это обеспечивает единообразие данных и показывает два представления одной персоны

3. **Сортировка правой ленты**:
   - Правая лента сортируется так же, как в Both Vertical (используя пары для сортировки):
     - **IN+OUT (Metriken)**: Сортировка по сумме метрик IN + OUT (по убыванию)
     - **Focus Time**: Сортировка по сумме "возрастов" фокуса пары (по возрастанию)
   - Для сортировки используются пары объектов (текущий участник и его партнер)
   - **Нет линий связи между парами** - нет привязки по парам, только сортировка
   - Это позволяет видеть отпечаток взаимодействия (порядок как в Both Vertical), но работать на собственной ленте

4. **Функции управления**:
   - **Левая лента (рабочая)**:
     - **Drag & Drop**: Перемещение объектов по ленте (работаем здесь)
     - **Общий фокус**: Фокус находится сверху левой ленты (на первом видимом объекте)
     - **Кнопка "↑ To Focus"**: Перемещает выделенный объект в общий фокус (сверху левой ленты)
     - **Особый фокус**: Круг над правой лентой в центре для отдельного рассмотрения объекта
     - **Кнопка "⬆ Special Focus"**: Перемещает выделенный объект в особый фокус (показывается на правой ленте)
     - **Кнопка "✕ Clear Special"**: Очищает особый фокус
     - **Двойной клик**: Редактирование объекта
   - **Правая лента (для просмотра)**:
     - **Только просмотр**: Показывает порядок с учетом взаимодействия (нельзя перемещать)
     - **Векторы IN/OUT**: Переключатель для выбора метрики:
       - **IN**: Показывает метрику удовлетворенности владельца (собственное удовлетворение)
       - **OUT**: Показывает метрику отклика партнера (как объект откликается у партнера)
       - Векторы направлены вправо (наружу от плоскости) для лучшей видимости
       - OUT векторы отображаются фиолетовым цветом для визуального различия
     - **Двойной клик**: Редактирование объекта
   - **Особый фокус**:
     - Круг над лентами в центре между двумя плоскостями (для лучшей видимости)
     - Показывается на overlay canvas, покрывающем весь экран
     - Позволяет отдельно рассмотреть объект, находящийся в особом фокусе
   - **Общие элементы управления**:
     - **Прокрутка**: Обе ленты прокручиваются синхронно
     - **Сортировка правой ленты**: Переключатель режимов сортировки (IN+OUT / Focus Time)
     - **Векторы правой ленты**: Переключатель для выбора метрики отображения векторов (IN / OUT)
       - Позволяет видеть либо собственное удовлетворение (IN), либо отклик партнера (OUT)
       - OUT векторы показывают, как объект откликается у партнера в процессе обмена

5. **Философия вертикальных лент**:
   - **Левая лента (собственный порядок)**: Порядок из горизонтальной Person Tape - здесь работаем, перемещаем, управляем
   - **Правая лента (порядок взаимодействия)**: Порядок из Both Vertical - смотрим, что происходит у нас на вертикали с учетом взаимодействия
   - Горизонтальная лента = собственный порядок пользователя (личная организация объектов)
   - Вертикальная лента = отражение взаимодействия (есть отпечаток пар для сортировки, но нет привязки по парам)
   - Мы работаем на левой ленте, но смотрим на правую, чтобы видеть, как объекты выглядят в контексте взаимодействия
